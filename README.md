# Retail Store Sales & Business Performance Analysis | Power BI

## Project Overview
This project focuses on analyzing retail store sales data using Microsoft Power BI. The objective is to understand sales performance, product trends, customer distribution, and promotional effectiveness through interactive dashboards.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Visualization
- Data Modelling

## Dataset Description

The dataset contains four tables:

1. **Dim Customers** – Customer details, city, and state.
2. **Dim Product** – Product names, categories, and prices.
3. **Dim Promotion** – Promotion names, advertisement types, and discount information.
4. **Fact Table** – Transaction dates, customer IDs, product IDs, units sold, and sales-related fields.

Total transaction records: 3,510.

## Data Cleaning & Transformation
- Performed data cleaning using Power Query.
- Handled missing values.
- Transformed data types.
- Combined information from multiple tables.
- Created relationships between tables.
- Prepared calculated fields for sales and discount analysis.

## Dashboard Features
- Interactive KPI Cards.
- Sales Trend Analysis.
- Product Performance Analysis.
- City-wise Sales Analysis.
- Promotion and Discount Analysis.
- Interactive Filters and Slicers.
